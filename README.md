# One Digital World, Many Cyber Risks

**CYBERGs 5.0 — Week 2 | Cloud, IoT & Critical Infrastructure | Kenya**

A short cybersecurity-awareness documentary project about the risks affecting cloud services, Internet of Things (IoT) devices, and essential digital infrastructure, with practical steps people can take to improve security.

## Project contents

- `index.html` — a small project showcase site suitable for GitHub Pages.
- `assets/one-digital-world-many-cyber-risks.mp4` — first-draft video.
- `assets/images/` — 15 AI-generated visual assets to use as storyboard images or still-image scenes.
- `docs/voiceover.md` — narration script and scene timings.
- `docs/sources.md` — source links to verify and cite in the final submission.

## Core message

Secure your devices. Protect your data. Help build a safer digital Kenya.

## Preview locally

Open `index.html` in a browser. The video and images use relative paths, so keep the folder structure intact.

## Publish with GitHub Pages

1. Create a new repository on GitHub named `cybergs-cloud-iot-documentary`.
2. Upload the files and folders from this project (upload the *contents* of this folder, not the ZIP itself).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site; the URL will appear in Settings → Pages.

## Before submitting

- Review the video and replace the computer-generated narration with your own voice if required by the challenge.
- Check the competition brief for the exact publishing, tagging, and evidence requirements.
- Verify every statistic against the original report before stating it in the video. The current script avoids relying on an unverified statistic.
- AI-generated visuals are illustrative, not documentary evidence or actual footage of a real cyberattack.
- Confirm that any music and third-party clips you add are licensed for your intended use.

## Suggested description

A short awareness documentary exploring cloud security, IoT risks, and the importance of protecting critical infrastructure in Kenya. It highlights everyday defensive practices including strong unique passwords, multi-factor authentication, software updates, and secure online accounts.
